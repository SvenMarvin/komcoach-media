# Komcoach Media

Öffentliche Ablage für freigegebene Social-Media-Bilder von Komcoach, damit
Buffer sie zum Veröffentlichen abholen kann. Nur Bilder, die ohnehin
öffentlich auf Instagram oder TikTok erscheinen. Keine Daten echter
Personen, App-Screens nur aus dem synthetischen Demo-Konto.

Quelle und Pipeline: privates Repo `komcoach-social`.
